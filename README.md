# V0LT4GE OV3RDRIVE / 极限过载

火元素法师对抗机械生物的像素管道射击游戏。低分辨率 Canvas 伪 3D、构成主义拼贴界面、全局色阶限制、五阶段同步音乐。

## 运行

需要 Node.js 22.12+ 和 npm。

```sh
npm ci
npm run dev
```

打开终端输出的本地地址。音频预载后尝试自动播放；浏览器允许时直接播放，限制自动播放时在首次点击或按键后启动。手机可连接电脑同一 Wi-Fi，访问终端显示的局域网地址。

```sh
npm run build      # 生成 dist/，可部署到静态网站托管
npm run preview    # 检查构建产物
npm test           # 纯逻辑与音频时序测试
npm run test:browser
```

浏览器测试默认使用已安装的 Google Chrome；无 Chrome 时先安装 Chrome，或修改 `playwright.config.js` 的浏览器配置。测试中的 `?qa=1` 调试接口仅开发模式提供，生产构建没有调试入口。

## 操作

| 操作       | 电脑             | 手机           |
| ---------- | ---------------- | -------------- |
| 环绕移动   | WASD 或方向键    | 战场上左右滑动 |
| 连发火球   | 按住 J 或 Z      | 按住火球按钮   |
| 终焰清图炮 | K 或 X           | 终焰按钮       |
| 暂停       | Esc 或右上角按钮 | 右上角按钮     |

左 / 下顺时针、右 / 上逆时针；角色初始位于管道下方，按右会向画面右侧移动。离开页面自动暂停。设置、语言、最高分与成就存储在当前浏览器。

移动中发射的火球继承角色 55% 的环绕速度，离手后保持自己的惯性；停止移动后发射则沿直线前进。可以利用走位打出不同的弹道。

## 规则与可调数值

- 生命上限 100，自然流失固定为 1.65 / 秒。击杀回血：余烬 11、烈焰 9、炼狱 8。普通受击保护和终焰无敌期间停止扣血。
- 击杀数 0 / 12 / 32 / 64 / 105 对应五阶段；整体难度另外影响生成间隔、敌速、伤害与分数。
- 开局终焰充满；24 次普通击杀充满一次，终焰击杀提供一半充能，障碍物不回血、不充能。
- 终焰立即回满生命；蓄力、首次爆发、主爆炸严格跟随原始音效时长。主爆炸清除当前敌人和障碍，音效结束后再保留 0.65 秒恢复保护。结束前角色闪烁。
- 早期敌人优先出现在玩家轨迹，轻度瞄准辅助与受击保护使开局能够靠击杀续命。

数值集中在 `src/balance.js`；纯玩法逻辑在 `src/game.js`，渲染在 `src/renderer.js`，界面与输入在 `src/main.js`，翻译在 `src/i18n.js`。

## 音频

20 个源音频均已接入。菜单 Fill → Menu、GameStart → Phase1、终焰三段由 Web Audio 采样时钟一次性排程。五个战斗循环从同一时刻开始，阶段变化只改变增益，以 0.65 秒交叉渐变维持相同音乐位置；菜单进入游戏淡出 0.35 秒。暂停冻结游戏音频时钟，设置点击声使用独立 UI 音频上下文。

菜单音乐、游戏音乐、音效分别控制音量，默认值为 70%、50%、80%。旧版单一音乐音量迁移为新的默认值，之后分别记住各自设置。

原始 `audioAssets/` 在本地保留并被 Git 忽略。仓库使用 `public/audio/` 中的发布版 FLAC，保持原采样率和精确采样数；不是原始浮点 WAV 的逐位复制。重新导出需要本地原素材、Python 3、FFmpeg 和 FFprobe：

```sh
python3 scripts/prepare-audio.py
```

完整时长、处理说明及验证边界见 [docs/AUDIO.md](docs/AUDIO.md)。

## 视觉与素材

原创火法师主视觉位于 `public/art/fire-mage.png`，使用内置 ImageGen 生成；最终提示词与素材说明见 [docs/ART.md](docs/ART.md)。游戏中角色、机械生物、粒子、隧道均为程序化绘制。Anton 字体通过 Fontsource 自托管，遵循其 SIL Open Font License。

管道、敌人和障碍物共享每帧前进路程与纵深投影；五阶段速度平滑增加，配色经过 1.2 秒像素网点过渡。纵深使用较缓和的对数映射，远处敌人从中心开口逐渐显现，越过玩家后继续向画外移动，完整轮廓离开视野才回收。装饰使用固定世界编号，同样只在画外回收。运动状态集中在 `src/tunnel.js`。Logo 的 4/A、3/E 通过独立裁剪的 3D 字面翻转，景深模糊跟随字面深度，其余字母保持前景层级。开启减少动态效果后使用静态 Logo。

Depth Attenuation 雾按世界纵深做指数平方衰减：远处管壁、敌人与障碍融入暗色雾中，火球和火花保留部分自发光；近处角色、移动轨道和 UI 保持清晰。管壁雾由十二边形表面的深度重建，随镜头和 FOV 对齐；缓存像素雾纹理保留印刷颗粒，避免每帧生成噪声。实现位于 `src/depth-fog.js`。

切换语言时，可见文字经过约 0.6 秒的 ASCII 扰码再依次归位；字符原位置保留占位，随机字符不改变排版，也不进入屏幕阅读器的语义文本。快速连续切换会取消上一次动画；减少动态效果开启时直接切换。

标题画面的锯齿分割线以 11fps 小幅移动，主视觉与得分保留轻微的印刷错位抖动。标题和制作人名字位置稳定；标题使用贴合两行文字的米白剪纸底板，左侧三个节点、右侧四个节点，右下露出少量红色错版边，边缘轻微抽帧变化。主菜单与二级页面共享纸张与红色底框的选中反馈，两层轮廓和角度各不相同，但在同一帧切换，按钮点击区域保持稳定。设置、作战指南、成就、暂停和结算页使用相同面板语言。相关样式在 `src/menu-motion.css`、`src/dialog.css`。

玩法方向参考 [Operius DX 官方介绍](https://distantillusions.com/games/operius-dx) 的多边形管道射击；角色、界面与实现为本项目创作。界面采用用户指定的 Persona 系列式斜切构图和高对比排版方向，没有使用其游戏素材。

## 已验证与待验证

- Node 测试：生命平衡、扫掠碰撞、阶段阈值、触屏角度、大招无敌及音频边界。
- 本机 Chrome：菜单与设置、语言和持久化、键盘及移动尺寸指针交互、暂停与继续、终焰和第五阶段、加载失败重试、构建资源。
- 桌面和 390×844 手机尺寸已检查截图。
- 真实 iPhone / Android 的操作手感、Safari 解码及真人听音仍需设备验证；浏览器自动化与数值模拟不代表这些检查已完成。
